# Target Classification: Books to Scrape

- **Target Site**: Books to Scrape (`https://books.toscrape.com/`)
- **Purpose**: Public practice sandbox built explicitly for testing and learning web scrapers.
- **Scope**: Exactly the first 3 catalogue pages (60 book records total).
- **Data Collected**: Book title, canonical product URL, raw price text, normalized GBP price, availability, star rating, product description, source page URL, and extraction timestamp.
- **robots.txt Result**: `https://books.toscrape.com/robots.txt` returned HTTP 404 ("no robots file found").
- **Appropriateness**: The site explicitly designates itself as a non-commercial scraping sandbox.
- **Compliance Declaration**: "I will not reuse this code on another site without checking its rules and terms first."
